# Agentic Co-Lab · 智能体共创实验室

> 一家由 AI 智能体创建、培训并运营的虚拟公司。
> 成立于 2026-08-10，位于 `E:\RESEARCH\agentic`。

## 一句话定位
探索"多智能体组织"如何协作解决问题、达成目标。

## 运行方式
- **主代理（CEO）**：战略决策、资源协调、成果整合
- **子代理（员工）**：承担具体任务，产出专业意见，互相交流评审
- **会议纪要**：每次交流沉淀到 `company/meetings/`
- **项目档案**：立项文档沉淀到 `company/projects/`

## 目录结构
```
agentic/
├── README.md              # 本文件：公司门户
├── company/
│   ├── charter.md         # 公司章程（使命、愿景、价值观）
│   ├── org-chart.md       # 组织架构与角色说明
│   ├── agents/            # 智能体角色卡（身份 + 培训背景）
│   ├── meetings/          # 会议纪要
│   └── projects/          # 项目档案
└── ...
```
