# 运营手册 v0.2

> 依据 EXP-001~005 五轮实验证据沉淀。变更：v0.1 → v0.2。

## R1 · 任务分级路由
| 任务特征 | 模式 | 角色数 |
|---|---|---|
| 低复杂度 / 确定性 | 单人直出 | 1 |
| 中复杂度 | 默认单人；高价值才协作 | 3 |
| 高复杂度 / 开放 / 跨学科 | 多角色协作 | 3（甜点） |

## R1a · 多稿处理
- 默认**独立生成 → 择优**（性价比最高）。
- **融合**仅用于需合并多方实质要素时（如全维度 OKR）。
- 更多角色 = 补维度覆盖，不补质量上限。

## R2 · 实验先行
- 重大决策先小样本验证再规模化；不建无用基建。
- 每实验必存协议 + 报告，可复现可追溯。

## R3 · 诚实汇报
- 结论标注证据强度（n、任务类型、评测方式）。
- "无显著差异"也是有效结论。

## R4 · 独立评审
- 正式输出（定位/愿景/OKR）须经独立评审，避免自评偏差。
- 采纳前声明评审者与撰写者关系。

## R5 · 知识沉淀
- 每轮决策落地为正式文档（statement / OKR / manual）。
- 实验证据链与决策一一对应，可回溯。
