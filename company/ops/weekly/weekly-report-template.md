# 周报模板 · Weekly Report

> 用法：复制本文件为新周报（命名规则见 `weekly-report-sop.md`），逐节填写；不要直接修改本模板。
> 状态符号（与 meeting-sop 一致）：✅ 完成　⏳ 待办/未开始　🔄 进行中　⚠️ 风险/阻塞
> 质量底线：每条产出必须有证据（Run 编号 / 文件路径 / 链接），无来源不写结论。

## 报告头
- **周期**：YYYY-Www（MM-DD ~ MM-DD）
- **主笔**：COO（运营部）
- **评审**：CEO @ 周会
- **归档日期**：YYYY-MM-DD
- **状态**：🔄 草稿 / ✅ 已归档
