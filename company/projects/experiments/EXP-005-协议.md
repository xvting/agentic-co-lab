# 实验协议 · EXP-005 角色数边际递减（3 → 5 → 7）

- **实验编号**：EXP-005
- **日期**：2026-08-10
- **主持/评审**：CEO（主代理）
- **关联**：EXP-001~004 → 回答"加角色还有没有用"

## 研究问题
多角色协作的质量收益是否随角色数增加而**边际递减**？3 → 5 → 7 角色，质量增量如何变化？

## 标准任务（开放战略类）
> 为 Agentic Co-Lab 制定 2026 下半年 **3 条关键目标**（OKR 目标层，每条一句话，总 ≤200 字），覆盖各角色最关注的维度。

## 嵌套设计（诚实声明：非独立采样）
招募 7 个不同角色代理，各自独立产出 OKR：
- **规模 3** = {研究员, CTO, PM}（与 EXP-001/004 同构）
- **规模 5** = 规模3 + {运营官, 市场官}
- **规模 7** = 规模5 + {数据科学家, 合规官}

评测各规模的**择优上限**（max 草稿质量）与**融合质量**，观察边际增量。

## 7 角色
研究员 / CTO / PM / 运营官 / 市场官 / 数据科学家 / 合规官

## 评测（CEO，5 维 × 1-5 = 25）
战略相关性 / 清晰度 / 覆盖广度 / 可执行性 / 创新性

## 局限
- 嵌套设计：3/5/7 非独立组，结论为"择优上限随 n 变化"的估计。
- n=1、单任务、单评审。
