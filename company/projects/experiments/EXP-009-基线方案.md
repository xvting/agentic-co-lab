# EXP-009 基线方案 · 支付成功率归因（首跑基线）

- **实验编号**：EXP-009（首跑基线）
- **日期**：2026-08-11
- **主持/督导**：研究院负责人（主代理）
- **授权链**：CEO → 研究院负责人（R7 两级授权）
- **任务来源**：`benchmark/tasks/task-analysis-attribution.md`（分析·推理类，5 节结构）+ `benchmark/tasks/rubric.md`（分析/推理类 5 维量表，总分 25）
- **目标**：为首个标准分析·推理任务建立第一批真实基线数据，回填 README「已知基线」。

## 1. 研究问题与设计意图

与 EXP-008（客观编码 + 测试套件）的关键差异：**EXP-009 为纯主观评测**——无客观套件，质量完全由 5 维量表决定；评审环节（盲评规范）成为流程核心。

**研究问题**：在开放式分析推理任务上，3 角色独立多稿的质量分布与择优上限如何？首跑只回答「基线长什么样」，不回答统计显著性。

**组设计（首跑）**：3 个独立执行代理（数据分析师 / 产品经理 / 支付工程师，对应任务文档「组设计建议」）各产 1 份归因分析 → 督导按 5 维量表盲评 → 择优稿 → 建立单人（单稿）/ 多稿（择优）基线。本跑**不做融合**（融合留待后续 EXP 对照），保持口径干净。

**角色视角设计意图**：三角色对同一数据有不同先验关注点——
- 数据分析师：切片定位、加权对账、周粒度拐点
- 产品经理：变更日志对齐、获客/注册侧混杂、用户路径
- 支付工程师：3DS2/SDK 技术链路、失败模式与可证伪验证

视角多样性是择优比较的意义所在；盲评保证角色标签不干扰质量判断。

## 2. 评测流程

1. **准备**：确认任务文档 + rubric 分析/推理类量表就绪（已完成自检，见附录）。
2. **生成**：3 个执行代理按第 5 节要求独立产出归因分析，落盘 `company/projects/experiments/EXP-009-runs/`。
3. **结构合规门槛**：督导核验每稿 5 节齐全、≤500 字、无过程解释；不合规退回该代理重写一轮（记录额外轮次成本），合规后方进入盲评。
4. **盲评准备**：督导对 3 稿脱敏（去除角色/代理可识别标记），分配匿名编号 A/B/C 并打乱顺序。
5. **盲评打分**：督导（评审，与撰写分离）按 rubric 分析/推理类 5 维逐稿打分并附依据。
6. **择优与揭盲**：按第 4 节规则确定择优稿；打分全部完成后揭盲，回填角色对应。
7. **基线落档**：记录质量分布、择优稿、成本；回填 README「已知基线」（建议行见第 6 节）。

## 3. 盲评规范（量表应用方式）

- **量表**：rubric.md 分析/推理类 5 维——归因严谨性 / 量化支撑 / 假设排除 / 决策可执行性 / 验证设计，各 1-5，总分 25。
- **评审与撰写分离**：执行代理只负责产出；评分由督导执行，评审不参与撰写（本跑督导为唯一评审）。
- **匿名编号**：稿件脱敏后随机分配 A/B/C；评审阶段不可见角色/代理对应关系；全部打分完毕才揭盲。
- **固定顺序**：逐稿 × 逐维打分（5 维 × 3 稿），避免跨稿锚定漂移；每稿附 1-2 句评分依据，保证可审计。
- **锚点对照**：打分时对照 rubric 1 分/5 分锚点，避免分数通胀；1-3 分区间如实使用。
- **自评声明**：执行代理如附带自评必须显式声明并单列，不计入督导盲评分。
- **多评审（可选 R4）**：如后续引入独立评审，各自独立打分后取均值并记录分歧；首跑为单评审，结论中声明「单评审主观分，非多评审均值」。

## 4. 基线指标定义

| 指标 | 定义 | 记录要求 |
|---|---|---|
| 结构合规率 | 5 节齐全 / ≤500 字 / 无过程解释 | 逐稿记录是否合规（门槛项，不计分） |
| 质量分布 | rubric 分析类 5 维 × 1-5（总分 25） | 每稿 5 维分 + 总分 + 评分依据 |
| 择优稿 | 总分高者优先 → 归因严谨性 → 量化支撑 → 验证设计 | 择优稿标识 + 理由；揭盲后回填角色 |
| 单人（单稿）基线 | 3 份独立稿质量分布（n=3） | min / 中位 / 逐份 |
| 多稿（择优）基线 | 择优稿总分 + 分维分（n=1 择优） | 择优稿完整记录 |
| 过程成本 | 代理数 × 轮次（含重写轮） | 记录实际值 |
| 诚实标注 | n=3、单轮直出、无融合、单评审、探索性 | 结论中显式声明 |

## 8. 已知局限（诚实声明）

- **n=3**：样本极小，仅作探索性参考线，不具统计意义。
- **单评审**：主观分为督导单次打分，非多评审均值，不视为稳定质量分。
- **无融合**：首跑单轮直出，择优稿 ≠ 融合稿；与 EXP-001/EXP-002「整合终版」口径不同，跨实验比较需注明。
- **主观无客观锚**：需以 rubric 锚点对照抑制分数通胀；5 维高分不自动等于结论正确（正确性以评审要点①-④核查为参考，不构成答案）。
- 首跑仅代表当前代理栈在单轮下的水平，模型/提示词/协议更新后需重跑。
