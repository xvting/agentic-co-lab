## 三、数据收集要求（R6a 核心章节）

### 3.1 检索渠道与来源分级

- **一级来源（冲突时以此为准）**：上交所 / 深交所 / 北交所官网及官方发布、中证指数公司、权威行情终端（Wind、东方财富 Choice、同花顺 iFinD）。
- **二级来源（主要引用层）**：证券时报、中国证券报、上海证券报、第一财经、财联社、东方财富、新浪财经、网易财经、同花顺财经、金十数据、每日经济新闻等。
- **三级来源（仅辅助，不作为关键数据依据）**：自媒体、聚合页、论坛。
- **独立来源定义**：不同发布主体/平台的原创报道，非同一稿件转载；同一数据须 ≥2 个独立来源（其中至少 1 个为二级及以上）一致方可入稿。
- **检索时点**：2026-08-11 15:00 收盘后；优先采集当日 15:00–22:00 发布的收盘报道；记录实际检索完成时点。

### 3.2 搜索关键词建议（执行团队可直接使用）

| 数据类别 | 建议关键词（可组合；日期写法可互换：2026年8月11日 / 2026-08-11 / 8月11日） |
|----------|-------------------------------------------------------------------------------|
| 指数表现 | "A股 收盘 2026年8月11日"；"上证指数 收盘 2026-08-11"；"深证成指 创业板指 收盘 8月11日"；"北证50 科创50 收盘"；"沪深300 上证50 收盘 涨跌幅"；"8月11日 三大指数 收评" |
| 成交与情绪 | "两市 成交额 2026年8月11日"；"A股 成交额 缩量 8月11日"；"沪深两市 成交额 8月11日"；"8月11日 上涨 下跌 家数"；"8月11日 涨停 跌停 家数" |
| 板块轮动 | "8月11日 领涨板块"；"8月11日 领跌板块"；"A股 板块 涨幅榜 跌幅榜 2026-08-11"；"行业板块 表现 8月11日" |
| 热点个股 | "8月11日 涨停个股"；"8月11日 地天板"；"8月11日 龙虎榜 异动"；"今日A股 热门股 8月11日" |
| 综合定性 | "A股 盘后总结 2026年8月11日"；"收评 8月11日"；"A股 收评 2026-08-11" |

提示：组合"日期 + 指标"检索更精准；同一关键词应在不同引擎/平台重复检索以获取独立来源；无法检索到当日数据的指标应在正文如实标注"当日未检索到权威来源"。

### 3.3 数据采集台账与逐项标注

- 建立《数据采集台账》（可并入《数据核验记录》或独立成档）：每项数据记录 6 字段——数据项 / 数值 / 来源（媒体名） / 来源链接（或报道标题） / 发布时间 / 口径备注。
- 正文中每个关键数字旁标注：来源 + 时点。示例：`上证指数 3934.09 点，跌 0.82%（来源：东方财富，2026-08-11 收盘）`。
- **识别并标注口径差异（常见清单）**：
  1. 成交额：沪深"两市"合计 vs "全市场"（含北交所），不同来源口径可能不同；
  2. 涨跌家数：是否含 ST、北交所、新股，统计时点；
  3. 板块分类：东方财富 vs 同花顺 vs Wind 板块名称与成分不同，领涨领跌榜可能不一致；
  4. 指数：收盘点位 vs 盘后快照；部分来源只给涨跌幅不给涨跌点；
  5. 个股成交：媒体"超 X 亿"为约数/转述，非交易所原始成交；
  6. 涨停/跌停：是否含 ST 板、北交所、是否剔除新股。
- **冲突处理**：两来源不一致 → 以一级来源（交易所/官方）为准；无一级来源且二级来源冲突 → 取多数一致值并标注"不同来源存在口径差异，以官方为准"；无法裁决 → 该数据降级为"媒体口径"或剔除出正文。

### 3.4 数据时效与更新

- 所有数据标注"截至 2026-08-11 收盘后 / 检索时点 X"；
- 盘后数据可能更新（如龙虎榜、大宗交易等以官方最终发布为准）；
- 同一指标检索到多个时点数值时，以最晚权威发布为准，并在台账记录差异。

## 四、执行要求（三角色）

### 4.1 主笔 · 研究员（撰写正文）

- **输入边界**：仅使用《数据采集台账》中已核验数据 + 公开常识；禁止引入未核验、非公开或"内幕/小道消息"；
- **禁止编造**：不出现台账之外的点位、涨跌幅、成交额、事件；
- **客观陈述**：趋势解读只做"当日数据可支持的归纳"，不预测次日/后市；
- **文字风格**：冷静、结构化、可读；段落短，多用表格；
- **交付**：《2026-08-11-A股盘后总结.md》（正文 + 数据说明），附初稿自检单（结构 8 节齐全）。

### 4.2 数据核验 · 数据科学家（检索、溯源与核对）

- 执行（或复核）联网检索并建立《数据采集台账》；
- 按"三、数据收集要求"逐项执行 ≥2 个独立来源交叉核验；数学一致性核对（指数涨跌点↔涨跌幅、成交占比、涨跌家数 vs 总数等）；
- 为每项数据标注来源 + 链接（或标题）+ 时点 + 口径；识别口径差异并分类标注；
- 发现不一致 → 标记 ⚠️（写入正文数据说明）或 ❌（回退主笔修订/补充检索）；修订后复检直至通过；
- 交付：《2026-08-11-数据核验记录.md》（含数据采集台账、逐项 ✅/⚠️/❌ 与通过/驳回结论）。

### 4.3 合规审查 · 合规官（风险与免责）

- 核查正文是否包含"不构成投资建议"的明确声明；
- 核查风险提示章节覆盖：行情波动、板块风险、数据局限（盘后可能更新）、媒体口径差异；
- 核查全文无诱导性措辞（如"抄底""必涨""推荐"）；
- 固定免责声明模板（沿用 TK-011，建议）：
  > 本文为市场信息整理与客观复盘，仅供参考，不构成任何投资建议，亦不构成任何收益承诺。市场有风险，投资需谨慎。文中所涉数据来自公开财经媒体及执行团队检索，可能存在滞后或误差，请以交易所及官方权威发布为准。据此操作，风险自担。
- 交付：《2026-08-11-合规审查意见.md》（逐条 ✅/⚠️，⚠️ 须整改后复审）。
