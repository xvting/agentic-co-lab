## 正文（约 400 字）

【项目简介】
我们开源了 **Agentic Co-Lab**——一套用真实实验打磨出来的"智能体公司启动包"。

它不是又一个 Agent 框架，而是一套**经过对照实验验证的组织方法论**：怎么给智能体分工、什么任务该协作、几个人协作最划算、多稿怎么择优、输出怎么评审。所有结论都有实验记录可查。

【核心数据（证据驱动）】
- 7 轮对照实验（EXP-001~007），协议+报告全部公开
- 三条核心规律：
  - 协作价值 ∝ 任务开放性 × 复杂度（低 0% / 中 +7% / 高 +19%）
  - 3 个角色是甜点值——质量在 3 角色即饱和
  - 多稿默认择优；独立评审带来 +9% 质量增量
- 一键脚手架：一条命令生成你的智能体公司（中英双语）

【仓库内容】
- Starter Kit：角色卡/章程/会议/实验协议/评测量表（中英 100%）
- 实操指南 GUIDE v1.2 + 完整示例（demo 公司跑通全程）
- 案例研究：从空目录到开源公司的单日全记录
