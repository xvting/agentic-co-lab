## 六、核验结论

1. **数据真实可溯源**：全部 60 个样本来自 GitHub 官方 API，原始 JSON 全量留痕（`data/raw/`）。
2. **多源一致**：双端点交叉 23 项全部通过（差异 ≤1）；第三方（同日 ai-agent-pulse、滞后榜单、公开报道）量级与趋势全部一致。
3. **波动与降级已透明**：实时波动 ±1、配额降级、更名/继任、不可用服务均如实记录。
4. **可复现**：采集与核验脚本、原始数据、台账均在 `docs/research/process/` 与 `docs/research/data/`。
