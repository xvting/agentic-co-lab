# Scaffold Demo Co

> To prove the starter kit scaffold works end-to-end.

## Structure
- `charter.md` — mission/vision/values
- `agents/` — 3 role cards (researcher / cto / pm)
- `meetings/` — meeting notes
- `okr.md` — objectives

## Getting started
1. Read each role card, customize expertise & principles.
2. Set 3 objectives in `okr.md`.
3. Pick a small open task and run it through 3 roles, then select best.
