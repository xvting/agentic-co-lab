# Rubric Template

> Purpose: standardize scoring, reduce subjective disputes. Objective cases first; fixed scales for subjective dimensions.
> Note: this file is only a scaffolding template for new companies/experiments; the authoritative benchmark rubric lives in `benchmark/tasks/rubric.md`.

## Objective cases (run code when possible)
- Case set: {{test_suite.py or case list}}
- Score: passed / total

## Subjective dimensions (each 1-5, with anchors)
| Dimension | 1 point | 5 points |
|---|---|---|
| Clarity | Confusing, ambiguous | Instantly clear |
| Differentiation | Generic | Unique, memorable |
| Executability | Can't be acted on | Clear handles/steps |
| Appeal (writing tasks) | Flat | Vivid, resonant |
| Completeness | Clearly missing pieces | Fully meets requirements |

## Blind review rules
1. Anonymize drafts before scoring (avoid affiliation bias).
2. If reviewer = author/integrator, **declare self-review bias**.

## Process cost
- Agents, rounds, elapsed time, token estimate (when available).
